# Language Skills Hub E1 – zkušební podsložka

Připraveno pro existující repozitář `ghrab-jazyky/ghrab-jazyky.github.io`.
ZIP obsahuje podsložku `zkusebni/`. Nenahrávejte ZIP rozbalený do kořene místo podsložky.
Po nahrání bude předpokládaná adresa `https://ghrab-jazyky.github.io/zkusebni/`.
Není potřeba druhý repozitář. V projektu nejsou skutečné karty ani klíče.
`basePath` je nastavená na `/zkusebni/`; všechny odkazy mají zůstat uvnitř této podsložky.
E1 nesmí používat Service Worker ani produkční IndexedDB.
Pokud je GitHub Pages nasazeno z `main` / `(root)`, není nutné měnit zdroj publikace.
Neodstraňujte README.md v kořeni existujícího repozitáře.
